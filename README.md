# Print Bridge

Share a USB-connected host-based printer over Wi-Fi using IPP and Bonjour/AirPrint discovery.

## Project variants

- [PrintBridge](PrintBridge/README.md) - current Windows version
- [PrintBridge-Win7](PrintBridge-Win7/README.md) - Windows 7-compatible version
- [PrintBridge-README.md](PrintBridge-README.md) - detailed project overview and setup guide

Both variants include their own launcher scripts, Python implementation, web interface, and dependency list.
